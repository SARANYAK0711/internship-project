# 🩺 AI Disease Prediction System

## 📌 Project Overview

The AI Disease Prediction System is a machine learning-based web application that predicts possible diseases based on user symptoms. The application provides instant predictions through an interactive and user-friendly interface.

This project was developed as part of my internship to demonstrate the practical application of Artificial Intelligence and Machine Learning in healthcare.

---

## 🚀 Features

- Disease prediction using Machine Learning
- User-friendly web interface
- Fast prediction results
- Easy symptom input
- Clean and responsive UI
- Beginner-friendly project structure

---

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- NumPy
- Scikit-learn
