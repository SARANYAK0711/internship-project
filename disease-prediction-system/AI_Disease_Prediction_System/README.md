# AI-Based Disease Prediction System Using Machine Learning

A beginner-friendly Python project that predicts the most likely disease based
on the symptoms entered by a user. It uses a **Decision Tree Classifier**
(scikit-learn) trained on a symptom–disease dataset.

> **Disclaimer:** This project is for **educational purposes only** and must
> **not** be used for real medical diagnosis. Always consult a qualified
> doctor.

---

## Problem Statement

Early prediction of diseases helps in timely diagnosis and treatment. This
application predicts a disease based on the symptoms entered by the user, so
that they can seek appropriate medical attention early.

## Objectives

- Load a symptom–disease dataset.
- Perform data preprocessing.
- Train a machine learning classification model (Decision Tree).
- Accept symptoms from the user.
- Predict the most likely disease.
- Display the prediction clearly.

## Dataset Description

- **Features (inputs):** 20 binary symptom columns (`1` = present, `0` = absent).
  Examples: `fever`, `cough`, `fatigue`, `headache`, `sore_throat`,
  `loss_of_taste`, `shortness_of_breath`, `joint_pain`, and more.
- **Target (output):** `disease` — one of 10 diseases:
  Common Cold, Influenza (Flu), COVID-19, Malaria, Dengue, Typhoid,
  Gastroenteritis, Migraine, Pneumonia, Food Poisoning.
- **Size:** 600 rows (60 samples per disease with small, realistic noise).

The dataset is generated by `generate_dataset.py`. You can regenerate or
extend it at any time.

## How to Run

1. **Install dependencies**

   ```bash
   pip install -r requirements.txt
   ```

2. **(Optional) Regenerate the dataset**

   ```bash
   python generate_dataset.py
   ```

3. **Run the application (interactive mode)**

   ```bash
   python disease_prediction.py
   ```

   You will see a numbered menu of symptoms. Enter the symptom numbers or
   names separated by commas, for example:

   ```
   Your symptoms: fever, cough, loss_of_taste, shortness_of_breath
   ```

4. **Run the demo (no keyboard input needed)**

   ```bash
   python disease_prediction.py --demo
   ```

## How It Works (Pipeline)

1. **Load** the dataset with Pandas.
2. **Preprocess** — split into features `X` and target `y`, fill any missing
   values with `0`.
3. **Train** a `DecisionTreeClassifier` and evaluate accuracy on a held-out
   test set (~95%).
4. **Accept** symptoms from the user (numbers or names).
5. **Convert** the input into a binary feature vector.
6. **Predict** the disease using the trained model.
7. **Display** the result with confidence scores.

## Results

- Test accuracy: **~95%** on the held-out set.
- Correctly classifies canonical symptom combinations for all 10 diseases.
